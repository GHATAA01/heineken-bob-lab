Build Your Own Bob Skill

4 steps. One file. Teach Bob something new — permanently.

⏱ +10 minutes 👥 For those who want to go further

? How Skills Work

A Bob skill is just a Markdown file in a specific folder. That's it.

  • Create a folder inside .bob/skills/ with any name
  • Add a SKILL.md file with a trigger phrase and instructions
  • Bob reads every skill file on every prompt — it activates automatically when you use the trigger phrase
💡 This is exactly how the discover-bw skill works. Someone wrote a SKILL.md file. You typed "Discover BW". Bob read the file and ran the workflow. There is no code, no plugin, no deployment.

1 Create the Skill Folder

In VS Code, open the Explorer panel and create the following folder inside .bob/skills/:

.bob/skills/my-glossary/
💡 How to create a folder in VS Code: Right-click on .bob/skills/ in the Explorer → New Folder → type my-glossary → Enter.

2 Create the SKILL.md File

Inside .bob/skills/my-glossary/, create a new file called SKILL.md.

💡 Right-click on the my-glossary/ folder → New File → type SKILL.md → Enter.

3 Paste the Template and Fill In Your Glossary

Copy the template below into your new SKILL.md file. Then fill in the Definition column — write the definitions in your own words.

---
name: my-glossary
description: >
  Lookup data terms. Triggers when the user types "lookup [term]".
  Returns a plain-English definition from the glossary below.
---

# My Data Glossary Skill

## Trigger
This skill fires when the user types: **lookup [term]**

## Behaviour
When triggered, search the glossary below for the term and return:
1. A one-sentence plain-English definition
2. One real-world example of where you encounter this in a data project

If the term is not in the glossary, say:
"I don't have [term] in the glossary yet.
Here is what I know from general knowledge: ..."

## Glossary

| Term          | Definition (fill in yours)   |
|---------------|------------------------------|
| COPA          |                              |
| InfoProvider  |                              |
| DSO           |                              |
| DTP           |                              |
| Transfer Rule |                              |
⚠️ Fill in at least 2 definitions before the next step — otherwise the skill won't have anything interesting to return.

4 Test Your Skill

Save the file. Then open a new Bob chat and type:

Type this in the Bob chat:

lookup COPA
✅ You should see — Bob returns your definition of COPA, plus a real-world example. Bob read your SKILL.md file and used your glossary.

Try a term that's not in your glossary:

lookup InfoCube
✅ You should see — Bob says it's not in your glossary but gives you what it knows from general knowledge — exactly as instructed in your SKILL.md.

💡 What This Means for Your Team

You just taught Bob a new behaviour in under 10 minutes, with no code, no deployment, and no configuration beyond a text file.

The same pattern scales to:

  • A project onboarding skill — "onboard me" → Bob explains the project structure and key contacts
  • A code review skill — "review this transformation" → Bob checks against your team's SQL standards
  • A data quality skill — "check data quality" → Bob runs your team's standard DQ checks on any table description
💡 Skills are shareable. Put your .bob/skills/ folder in a shared git repo. Every team member gets the same Bob capabilities — automatically, on every prompt.
