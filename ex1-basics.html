Exercise 1 — Both Tracks

Bob Basics

Three quick wins to get comfortable with Bob before your track exercise.

⏱ 10 minutes 👥 Everyone
🏠 Start 1 · Basics 2A · BW 2B · Databricks 3 · MCP ⭐ Finale

🗺 Opening the Bob Chat

You should have Bob IDE open with your starter kit folder loaded. Now open the chat panel:

  1. Look at the left sidebar in Bob IDE — find the Bob chat icon (small chat bubble). Click it.
  2. The Bob chat panel opens. At the bottom you'll see the input box — this is where you type your prompts.
  3. Click + New Chat (or the pencil icon at the top of the panel) to start a fresh conversation.
  4. Press Enter to send. Use Shift + Enter for a new line without sending.
💡 Can't find the chat icon? Press Ctrl + Shift + P, type Bob, and select Bob: Open Chat.
⚠️ VM tip. Bob's first response in a session may take 15–30 seconds while it initialises. Subsequent responses are faster. If nothing appears after 45 seconds, press Stop in the chat and try again.

🔀 Bob's Three Modes — Pick the Right One

Bob has three modes. Knowing which to use saves you time and avoids confusion. You switch modes with the / command, or via the mode dropdown at the top of the Bob panel.

Mode What it does Use it when… Today's exercise
💬 Ask Answers questions. Reads your files. Never writes or edits anything. You want an explanation, a summary, a comparison, or an analysis — with no risk of Bob changing any file. Tasks 1, 2 & 3 below
📋 Plan Thinks through a multi-step problem and produces a structured breakdown or proposal. Does not execute — it plans only. You have a complex task (architecture design, sprint planning, migration strategy) and want Bob to reason through it before taking any action. Wow Moment finale
⚡ Agent Reads files, writes files, triggers skills, and calls MCP tools. Full action mode — Bob gets things done. You want Bob to generate artefacts, update a document, run a skill workflow, or connect to an external system. If in doubt, use Agent. Exercises 2 & 3
💡 Simple rule of thumb: Use Ask to understand something. Use Agent to get something done. Use Plan when the task is big and you want to review Bob's thinking before it acts.
💡 How to switch modes: Type /ask, /plan, or /agent at the start of any message — or click the mode name shown at the top of the Bob panel to open the mode selector dropdown.

1 Ask Bob a Question

Bob has deep knowledge of data, analytics, SAP BW, and Databricks — built in, no internet needed. Let's test it.

Type this in the Bob chat:

What is SAP BW COPA and why are companies migrating to Databricks?
✅ You should see — a clear paragraph explaining COPA (CO-PA: Profitability Analysis) and the main migration drivers (cost, scalability, open formats).
💡 This is Bob's built-in knowledge. No file, no internet — just ask. Bob works like a very well-read colleague.

2 Reference a File with @

Bob can read any file in your workspace. Use the @ symbol to point to it. Every starter kit contains BW Metadata/BW Metadata.txt — a real Heineken COPA metadata export. Try these three prompts in order. Each one shows a different way Bob can work with a file.

💡 The @ autocomplete. As you type @/, Bob shows a dropdown of files in your workspace. Pick from the list — no need to type the full path.

Prompt A — Summarise

Start simple: ask Bob to read the file and give you a structured summary.

Type this in the Bob chat:

@/BW Metadata/BW Metadata.txt
Summarise the data sources in this file as a table. Include the object name and object type for each.
✅ You should see — a Markdown table listing SAP BW objects (HANA views, DataSources, transformations, ADSOs) and their types.

Prompt B — Ask a specific question

Now ask Bob something that requires it to reason over the file, not just read it.

Type this in the Bob chat:

@/BW Metadata/BW Metadata.txt
How many transformation objects are in this metadata? For each one, what is the source and what is the target?
✅ You should see — a count of transformations and a list showing each one's source object and target object. Bob extracted this by reading the file structure, not just scanning for keywords.

Prompt C — Ask for a judgement

Now push further: ask Bob for an opinion based on what it read.

Type this in the Bob chat:

@/BW Metadata/BW Metadata.txt
Based on this metadata, which object looks most complex to migrate to Databricks and why? Give me one sentence.
✅ You should see — Bob naming a specific object (likely a transformation with custom ABAP logic or an ODP-delta DataSource) and giving a plain-English reason. This is Bob as an analyst, not just a reader.
💡 Notice the progression. Prompt A = extract. Prompt B = reason. Prompt C = judge. The same file, three different depths. This is how you work with Bob on any document in your project.
⚠️ Watch out — file paths are case-sensitive. Copy prompts exactly as shown, or use the @ autocomplete dropdown.

3 Try the Mode Switch in Action

Now let's use Ask mode explicitly with a /ask command. This guarantees Bob answers your question without touching any file — useful when you're exploring or learning.

Type this in the Bob chat:

/ask What does Bronze, Silver, Gold mean in a Databricks Medallion architecture? Give me a one-line description of each layer.
💡 Try the / command palette. Type / alone in the input box (nothing else) and wait a moment — you'll see a dropdown listing all modes and commands. This is also where skills appear once they're loaded.
✅ You should see — three clear one-line descriptions: Bronze = raw ingestion, Silver = cleaned and validated, Gold = business-ready aggregated data.
💡 Quick recap — which mode are you in for each exercise today?
  • Tasks 1–3 here → Ask (reading and understanding only)
  • Exercise 2 (BW Discovery / Foundation analysis) → Agent (Bob generates artefacts)
  • Exercise 3 (MCP connection) → Agent (Bob calls a live API)
  • Wow Moment → Agent (Bob synthesises and generates the sprint table)
